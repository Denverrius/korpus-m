## 1. Запуск сайта локально
Сайт полностью автономен. Открыть файл `index.html` в любом браузере:
```powershell
Start-Process "E:\Antigravity\Jarwis\korpusm_mariupol\index.html"
```

## 2. Запуск Telegram-бота
1. Создайте файл `.env` в папке `korpusm_mariupol/`:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   MASTER_CHAT_ID=ваш_telegram_id_для_получения_заявок
   ```
2. Запустите скрипт:
   ```powershell
   python "E:\Antigravity\Jarwis\korpusm_mariupol\bot.py"
   ```
